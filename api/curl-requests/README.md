# Yeti Homes API Curl Scripts

## Quick Start

```bash
# 1. Setup auth (creates admin account + saves token)
bash auth-setup.sh

# 2. Seed all data (70 requests across all endpoints)
bash set-all.sh
```

## Directory Structure

```
curl-requests/
├── auth-setup.sh              # Register + login, saves token to .auth_token
├── set-all.sh                 # Run all seeding scripts in order
├── .auth_token                # Generated by auth-setup.sh (gitignored)
├── cookies.txt                # Generated by auth-setup.sh (gitignored)
│
├── properties/                # 35 property scripts
│   ├── house-{1..10}.sh       # Houses (Baneshwor, Budhanilkantha, Tokha, etc.)
│   ├── property-{1..10}*.sh   # Mixed houses, apartments, lands
│   ├── prop-{1..15}*.sh       # Houses, apartments, lands (new batch)
│
├── teams/                     # 5 team member scripts
├── reviews/                   # 8 review scripts
├── blogs/                     # 6 blog article scripts
├── faqs/                      # 8 FAQ scripts
├── affiliations/              # 5 affiliation/partner scripts
├── company-info/              # 1 company about-us script
├── content/                   # 2 static page scripts (About, etc.)
├── legal-docs/                # 3 legal document scripts
├── contact/                   # 1 support ticket script
├── inquiries/                 # 3 property inquiry scripts
└── newsletters/               # 1 newsletter subscription script
```

## Auth

All POST/PUT/PATCH/DELETE scripts require authentication. The `auth-setup.sh` script:
1. Registers `admin@yetihomes.com` / `Admin@123456`
2. Logs in and saves the JWT token to `.auth_token`
3. `set-all.sh` reads the token and passes it as `$AUTH_TOKEN` to every script

## Default Admin Credentials

- **Email:** admin@yetihomes.com
- **Password:** Admin@123456

## Individual Scripts

You can also run scripts individually:

```bash
# Seed just properties
for f in properties/*.sh; do bash "$f"; done

# Seed just teams
for f in teams/*.sh; do bash "$f"; done

# Run a single script
bash properties/prop-1-house.sh
```
